Live numbers exclude this editor window. Close the editor (the overlay keeps running from the tray) for the smallest footprint.

  • The crosshair is a tiny window sized to your design, not a full-screen layer.
  • Nothing redraws while the crosshair is idle. Animations only render while they play.
  • The global input hook only runs while a layer uses an animation and the overlay is visible.
  • It never injects into or reads from the game, so it is safe with anti-cheat.

Compatibility

The crosshair is a separate transparent window drawn on top of everything. It always shows over borderless windowed and windowed games. For games set to Fullscreen, pick Fullscreen games under Display mode on the Home tab; that works as long as Windows’ fullscreen optimizations are on for the game (the default). True exclusive fullscreen can still hide it.
